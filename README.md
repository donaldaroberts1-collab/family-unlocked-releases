# Family Unlocked — downloads

Installers for **Family Unlocked**, the desktop app by DTR Operations Group that
keeps a family's estate plan, contacts, accounts, documents and wishes in one
encrypted file on their own computer, with a calm step-by-step guide for
whoever is left. No account, no cloud, no network.

This repository holds only the installers; the app's source is private.

**Always-current links**

- Mac (Intel and Apple silicon, macOS 12 or later):
  https://github.com/donaldaroberts1-collab/family-unlocked-releases/releases/latest/download/Family-Unlocked-Mac.dmg
- Windows 10/11 (64-bit):
  https://github.com/donaldaroberts1-collab/family-unlocked-releases/releases/latest/download/Family-Unlocked-Windows-Setup.exe

The Mac app is signed and notarized by Apple. The Windows installer is not yet
signed: Windows shows "Unknown publisher"; choose Run (or More info › Run anyway).
